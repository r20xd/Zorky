# Ролики для оценки (P32)

Файлы лежат вне git: `demo/videos/`. Скачать и сверить SHA256: `py -m eval.videos fetch` (из папки `ml/`).
Страница проверки: `py -m eval.videos review` -> `ml/eval/review.html`. Разметка: `py -m eval.videos labels` -> `ml/eval/labels.json`.

Интервалы нарушений - **черновик**: по просмотру кадров с шагом 1-2 с, не по детекциям модели; точность около 1 с. Утверждает человек.
**GMDCSA-24 целиком: 160 роликов** (79 падений `gmdcsa-sN-fall-NN`, 81 бытовой сценарий `gmdcsa-sN-adl-NN`; Zenodo 10.5281/zenodo.13354453, CC BY 4.0).
Источник разметки - **CSV авторов набора** (`Subject N/Fall.csv`, `ADL.csv`, колонка Classes: `Falling (SW)[3.4 to 6]`), не на глаз. Строки gmdcsa-* генерирует `py -m eval.gmdcsa sync`, руками не правятся.
Интервал `fall a-b` - класс Falling у авторов: от начала падения до конца ролика (с лежанием). Бытовые сценарии (лёг на кровать, сел, ходьба, чтение, упражнения) без меток - проверка ложных падений.
**Предупреждение:** в роликах GMDCSA-24 человек лежит меньше 10 с (ролики 4-16 с), поэтому неподвижность (`immobile`) на них не проверить; метки immobile для GMDCSA не ставятся.

## Сценарии, для которых ролик не нашёлся

- **Перелезание через ограждение (fence_crossing)**: на Mixkit по тегам fence, climbing, construction нет человека, перелезающего забор (есть скалолазание и люди за сеткой). Не нашлось.
- **Сближение с техникой (`vehicle_proximity`)**: на Mixkit техника есть (погрузчик), но человека рядом с ней нет. Pixabay 26239 - негативный пример (рабочий в ~3 м от экскаватора, ниже порога vehicle_proximity, проверено человеком). Нужна съёмка (P33).
- **Подлезание под груз/конвейер (`under_load`)**: ролик с конвейером есть, человека под ним нет. Нужна съёмка (P33).
- **Телефон в опасной зоне**: ролики с телефоном - бытовые, не промплощадка; годятся только как проверка детекции телефона.
- - **Pixabay (поиск API, 2026-10-23)**: перелезание через забор (fence_crossing) - не нашлось: по запросам "climbing fence", "jump over fence" только альпинизм, ворота, спорт. Телефон у оборудования - не нашлось: по "worker phone machine", "using smartphone factory" только бытовые ролики и техника без людей. Бег на стройке ("running construction site"): подходящих нет. Страница Pixabay и лицензия Pixabay Content License - в Release нельзя. mp4 с cdn.pixabay.com скачивается без ключа с браузерным User-Agent (проверено curl и командой fetch); ссылка содержит дату и хеш, при её смерти - скачать вручную со страницы.
